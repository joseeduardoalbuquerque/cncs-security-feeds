# Política de segurança

Não abra uma issue pública para comunicar vulnerabilidades, credenciais expostas, dados pessoais ou detalhes confidenciais de incidentes.

Use os mecanismos privados de reporte de segurança do GitHub quando estiverem disponíveis no repositório. Revogue imediatamente qualquer credencial publicada por engano; apagar um commit não elimina o segredo do histórico nem garante que não tenha sido copiado.
